An addon mod for **TerrafirmaCraft (TFC:TNG)** that reworks how **Jams** and **Preserves** behave. It also makes adding a Lid data driven with a custom return chance.

## Features
* Jar lids are now returned to the player when opening jars.
* **Jams** and **Preserves** now show what lid was used to seal the jar
* **Jams** can be sealed back into **Preserves**
* Opening a **Preserve** is as easy as right-clicking it

## Compatibility
* Firmalife
* KubasTFCAdditions
